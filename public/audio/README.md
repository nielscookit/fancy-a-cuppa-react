# V3 custom timer sounds

Upload the new audio files here without replacing the original media:

- `Memo.mp3`: proposed replacement for the Almost Time cue (30 seconds remaining).
- `Ready.mp3`: proposed replacement for the completion cue.

Uploading does not activate a sound. The development step will validate the files
and select them explicitly. Original `AlmostTime.mp3` and `tea-finished.mp3`
remain available through the pinned V2 media manifest and build process.

Custom completion looping is a requested follow-up, not implemented by this
folder. Foreground playback can repeat until Reset. iPhone Web Push cannot play
these MP3 files or provide a continuous custom alarm on the lock screen.
