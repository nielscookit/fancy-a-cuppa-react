# Fancy a Cuppa V3 – Kategorie-PNGs

Vier unveränderte Original-PNGs aus der freigegebenen Designvorgabe gehören hierher:

- `black-tea.png` (Datenbankschlüssel `black`)
- `green-tea.png` (Datenbankschlüssel `green`)
- `fruit-tea.png` (Datenbankschlüssel `fruit`)
- `herbal-tea.png` (Datenbankschlüssel `herbal`)

Die Bilddateien müssen exakt so heißen. Die Pfadzuordnung und alle
individuellen Crop-/Scale-/Position-Werte liegen ausschließlich in
`src/features/categoryImages.js`; die TeaCard enthält keine Dateinamen.

Unbelegte Kategorien zeigen Soft Lime `#E8FBCB` ohne Ersatzbild und ohne Symbol.
Ein Ladefehler bei einer PNG führt ebenfalls zu Soft Lime.

Die PNGs werden unverändert übernommen, nicht in WebP konvertiert.
